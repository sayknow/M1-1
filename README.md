# 한국 경제 물가압력 시계열 분석

한국은행 ECOS의 월별 원/달러 환율, 기준금리, 소비자물가지수(CPI)를 이용해
2015년 1월부터 2025년 12월까지의 동시점 및 선행 시차 상관관계를 분석합니다.

## 사용 데이터

| 변수 | ECOS 통계표 | 항목 | 주기·단위 |
|---|---|---|---|
| 원/달러 환율 | `731Y004` | `0000001` 원/미국달러, `0000100` 평균자료 | 월, 원/USD |
| 한국은행 기준금리 | `722Y001` | `0101000` 한국은행 기준금리 | 월, 연% |
| 소비자물가지수 | `901Y009` | `0` 총지수 | 월, 2020=100 |

환율은 일별 자료를 임의 집계하지 않고 ECOS가 제공하는 공식 월평균 계열을 사용합니다.

## 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# .env의 ECOS_API_KEY를 발급받은 키로 변경
python main.py
```

`.env.example`은 공개 테스트 키 `sample`을 제공합니다. 이를 `.env`로 복사한 뒤 로컬에서만
개인 키를 설정하세요. `.env`는 Git에서 제외되며 커밋하지 않습니다. 공개 테스트 키도 전체 파이프라인을
재현하지만 호출당 10건 제한 때문에 느립니다. 개인 키는 더 큰 페이지로 조회합니다.

## 처리 및 해석

- 원자료는 `data/raw/`, 월별 병합·파생 데이터는 `data/processed/`에 저장합니다.
- `exchange_yoy`와 `cpi_yoy`는 12개월 전 대비 백분율 변화, `base_rate_change`는
  전월 대비 퍼센트포인트 변화입니다.
- `exchange_lag_k`와 `base_rate_lag_k`는 월 `t`에서 각각 `t-k`의 변화율/변화폭입니다.
- `output/lag_correlations.csv`는 0~12개월 선행 시차별 Pearson 상관계수를 담습니다.
- 상관관계는 인과관계를 뜻하지 않습니다. 금리는 물가에 반응해 결정될 수 있고,
  국제유가·수요·공급망 같은 공통 요인이 세 변수에 함께 영향을 줄 수 있습니다.

## 저장된 자료로 추가 분석 실행

```bash
python -m src.topic3
python -m src.significance
```

`topic3`는 모든 시차를 동일한 108개월로 비교하고, `significance`는 같은 달의
상관과 두 상관의 차이를 원형 블록 부트스트랩 20,000회로 검증합니다.
금리 변화폭과 CPI 상승률의 양의 상관은 유의했지만 두 상관의 차이는 유의하지 않았습니다.
이는 탐색적 결과이며 인과효과를 입증하지 않습니다.

전체 과정과 한계는 [통합 분석 리포트](output/통합_분석_리포트.md)에 정리했습니다.
커밋 전 `python -m src.check_secrets`로 로컬 `.env`의 비밀값이 Git 이력과
인덱스에 포함되지 않았는지 확인할 수 있습니다. 이 검사는 로컬 비밀값과의 일치 검사이며
모든 종류의 비밀을 탐지하는 일반적인 스캐너는 아닙니다.
